Запустите Docker Desktop. В папке проекта выполните: py tools/ib.py start
Или откройте START.cmd. Сайт: http://localhost:8080
Аккаунты передаются отдельно. Их загрузка и перенос на флешке описаны в README.md.
При обновлении существующей установки: резервная копия, git pull --ff-only, py tools/ib.py start --build.
