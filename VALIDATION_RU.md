# Проверки выпуска

База исходников: `ghosttik368-lgtm/ib-school`, main `46fb597ee8ee228ed56a21e7a64e211756aaf694`. Старые миграции сохранены побайтно; добавлена accounts.0003 для смены выданного пароля.

- Django 5.2.17, Python 3.12: **144 теста прошли**, включая обновление прежних миграций, доступы, студию, прохождение, C++, сообщения, AI и выдачу аккаунтов.
- `check`: ошибок нет. `makemigrations --check --dry-run`: изменений нет.
- 5 проверок CLI: автономный запуск без сборки/скачивания, отказ при несовпадении образов, контроль исходников, сохранение существующих настроек, импорт только файла хешей.
- Проверены все 1000 выданных паролей относительно хешей; роли 850/100/50, уникальность логинов и паролей, целостность SQLite и внешние ключи. Курсов в стартовой базе нет.
- Chromium: проверены главная, вход, студия, редактор, чат, аналитика, группы, экран AI-теста и страница практики. Проверены поиск, переход шага мастера, уведомления, скрытие управления у студента. Ошибок JavaScript нет; горизонтального переполнения на главной при ширинах 320, 390, 768, 1024 и 1440 px нет.
- Шрифты содержат кириллицу; логотипы совпадают с предоставленными оригиналами.
- 8 проверок отдельного установщика оформления: резервирование, совместимость, повторная установка, откат и отказ при изменённых локальных файлах.

Полный Docker-стек и модели не выполнялись в среде подготовки этого архива: здесь нет Docker Engine. В репозиторий добавлен GitHub Actions workflow `Verify platform`: сборка образов, PostgreSQL, HTTP и реальная проверка C++. Его фактический результат смотрите на вкладке Actions. Загрузка и качество реальной Qwen/Whisper проверяются на целевой машине командой `py tools/ib.py check` и на вашей лекции.

USB-комплект с многогигабайтными образами и весами создаётся на исходной Docker-машине командой `export-usb`. В исходный ZIP проекта образы и веса не включены. Перенос между разными архитектурами CPU и нагрузка 1000 одновременных пользователей не проверялись.
