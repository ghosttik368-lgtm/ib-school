# C++ на сайте

## Для ученика

В блоке «Практика C++» доступны редактор с подсветкой C++20, номерами строк, автоматическими скобками и отступами; автосохранение, скачивание .cpp, восстановление кода из истории.

1. Напишите решение, читающее данные из stdin (`std::cin`) и печатающее ответ в stdout (`std::cout`).
2. Для пробы заполните «Свой ввод» и нажмите «Запустить на своём вводе» (Ctrl+Enter). Вывод и ошибки появляются сразу под кнопками после завершения.
3. Нажмите «Отправить на проверку». Проверяются скрытые тесты преподавателя. Балл начисляется один раз, только после успешного прохождения всех тестов.
4. Пока отправка выполняется, можно редактировать следующий вариант или отменить текущую. После обновления страницы статус восстанавливается.

Это запуск с заранее заданным stdin, а не интерактивная командная оболочка. Другие языки, сторонние библиотеки и сетевой доступ не предоставляются. Поддерживается C++20, GNU g++ из runner/Dockerfile.

## Для преподавателя

В редакторе курса добавьте блок «Практика C++», заполните условие, форматы ввода/вывода, примеры, стартовый код, ограничения и пары «ввод — ожидаемый вывод». Поддерживается до 100 тестов. Сохраните и опубликуйте курс. Примеры в условии доступны ученику, скрытые тесты и эталонное решение ему не передаются.

Ответ сравнивается по словам/числам: количество пробелов и переносов строк несущественно. Числа с плавающей точкой сравниваются как строки, без погрешности. Для принятого в очередь решения тесты и лимиты фиксируются: последующее редактирование задания не меняет эту проверку.

## Что исправлено в выпуске

- Worker восстанавливается после временной недоступности Docker/БД. Зависшая отправка получает новую попытку после истечения аренды (120 секунд без heartbeat). Всего до двух автоматических повторов; после этого показывается ошибка сервиса.
- Автоматический повтор не создаёт новую отправку и не начисляет повторные баллы. Ошибки решения (WA/CE/TLE и т. д.) автоматически не повторяются.
- Повторная отправка того же HTTP-запроса защищена ключом идемпотентности. UUID работает и без crypto.randomUUID.
- Успешная компиляция повторно используется для неизменённого кода в пределах одного worker. Кэш в памяти ограничен восемью программами, при перезапуске очищается. Каждый тест по-прежнему выполняется в новом изолированном контейнере.
- Редактор CodeMirror 5.65.20 включён в исходники вместе с лицензией MIT. CDN и доступ студента к Интернету для редактора не нужны.
- Повторные запуски, восстановление аренды, отмена, защита скрытых ответов и однократное начисление проверяются тестами. CI дополнительно выполняет 20 последовательных запусков настоящего C++ в Docker.

Без журнала с проблемного сервера нельзя утверждать, что конкретная ошибка «после двух использований» воспроизведена. Устранены обнаруженные в коде причины отказа; целевой сервер проверяется командой ниже.

## Обновление существующего Docker-развёртывания

В папке проекта:

```bash
sh compose.sh backup
git pull --ff-only
sh compose.sh up -d --build
sh compose.sh ps -a
```

Миграция practice.0002 добавляет поля отправок автоматически через initialize. Старые курсы, решения, аккаунты и баллы сохраняются. AI остаётся отключённым, если ранее был выключен. Не удаляйте .env.deploy и Docker volumes.

Проверка на сервере с настроенным SSH-runner:

```bash
sh compose.sh exec -T judge python backend/manage.py check_runner --repeat 20
sh compose.sh logs --tail 100 judge
```

Локально вместо judge используется judge-local. Первоначальное подключение VM: [SERVER_RU.md](SERVER_RU.md). Runner/Dockerfile в этом выпуске не менялся, пересобирать его на VM для этого обновления не нужно. GPU не требуется. Схема изоляции сохраняется: серверный worker подключается к отдельной VM по SSH; студент работает только на сайте.

Порты прежние: сайт 80/443, web 8000 и PostgreSQL 5432 внутри Docker, SSH runner обычно 22. [Полный перечень](PORTS_RU.md).
