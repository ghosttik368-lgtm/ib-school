**Проверки обновления Git / Docker**

Проверено на копии исходников M5/M6 + AUTOQUIZ, Python 3.12, Django 5.2.17. На компьютере пользователя изменения выполнит установщик.

- Проверка синтаксиса новых Python-файлов на совместимость с Python 3.10.
- Проверки Django, отсутствие новых изменений моделей и применение существующих миграций на тестовой SQLite.
- 137 тестов: доступ, Studio, прохождение, рейтинг, C++, сообщения, преподавательский интерфейс, AUTOQUIZ и проверки интеграции Docker. Запуск с `DEV_DISABLE_MFA=0`; тесты локального режима включают этот параметр явно.
- В установщике проверены замена названия, сохранение `.env` и миграций, сохранение пользовательского `.gitignore` и повторный запуск.
- Вспомогательные команды проверены на создание настроек без замены секретов, запрет случайного переключения локальной установки в серверную и исключение секретного файла из Git.
- Реальный `docker compose config --quiet` проверил локальный вариант с AI/C++, серверный вариант с удалённым Docker по SSH и вариант с уже существующим HTTPS-прокси.
- Экспорт/импорт проверен на синтетических данных между двумя SQLite: сохранены ID аккаунтов, хеши паролей, права, курсы, опубликованный тест с привязками к видео и сами файлы. Повторный импорт в непустую установку отклонён.

Полный Docker build/up здесь не выполнялся: Docker daemon недоступен. Не выполнены реальные проверки PostgreSQL в контейнере, SSH к серверу кафедры, выпуска HTTPS-сертификата, компиляции C++ на этой VM и генерации вопросов реальной моделью в новом контейнере. Резервное копирование/восстановление через PostgreSQL также требует проверки на тестовой серверной установке. Их порядок и ожидаемые результаты приведены в `DEPLOY_GUIDE_RU.md`.

Для повторения тестов на Windows после установки:

```powershell
$env:DEV_DISABLE_MFA = "0"
.\.venv\Scripts\python.exe backend\manage.py test access studio learning practice messenger teaching autoquiz config.tests_deployment
Remove-Item Env:DEV_DISABLE_MFA
```

В текущем архивном исходнике встречалась ранняя версия входа, не учитывавшая уже предусмотренный параметр локального отключения MFA. Установщик добавляет поддержку этого параметра только для этой известной версии; если прежняя правка у тебя уже стоит, сохраняет её. В серверных настройках локальное отключение не применяется.
