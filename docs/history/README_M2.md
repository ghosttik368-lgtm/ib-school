# ИБ · обновление M2

M2 — создание, наполнение и публикация курса. Это обновление поверх работающей M0/M1 с последним исправлением, отключающим 2FA в локальной разработке. В архиве полные версии изменённых файлов и новые файлы. Ручная вставка фрагментов кода не требуется.

## Установка в Windows 11

1. Остановите Django в терминале: **Ctrl+C**.
2. Сделайте копию текущей папки проекта целиком в другую папку, например `cyber_coures_backup_before_M2`. Сохраните `backend/db.sqlite3`, `backend/media`, `.env`, исходники и историю миграций. Резервную копию не запускайте одновременно с основной платформой.
3. Распакуйте архив обновления во временную папку. Из него скопируйте папки **backend** и **frontend**, а также **requirements.txt** и **README_M2.md** в текущую папку проекта, рядом с существующим `backend/manage.py`. Подтвердите замену совпадающих файлов. Копируйте содержимое с объединением папок — не удаляйте старые папки перед копированием.
4. В VS Code откройте текущий проект. Все команды выполняйте в PowerShell из корня проекта, где находится requirements.txt.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe backend\manage.py check
.\.venv\Scripts\python.exe backend\manage.py makemigrations --check --dry-run
.\.venv\Scripts\python.exe backend\manage.py migrate --plan
.\.venv\Scripts\python.exe backend\manage.py migrate
.\.venv\Scripts\python.exe backend\manage.py import_legacy_courses
.\.venv\Scripts\python.exe backend\manage.py test access studio
.\.venv\Scripts\python.exe backend\manage.py runserver 127.0.0.1:8000
```

Вводите по одной команде. При ошибке остановитесь и сохраните её текст. Не удаляйте миграции и не используйте `--fake`.

Ожидаем: `System check identified no issues`, `No changes detected`, новые миграции `courses.0002`, `courses.0003`, `studio.0001` с результатом `OK`; затем сообщение о добавлении существующих курсов в редактор; в конце тестов — `Ran 35 tests` и `OK`. Порядок применения независимых миграций может отличаться.

Откройте **http://127.0.0.1:8000/management/**. Если браузер показывает старое оформление, нажмите **Ctrl+F5**. Вход остаётся по логину и паролю; при локальном DEBUG=1 2FA по-прежнему отключена. `.env`, база и загруженные файлы в архив не входят и не заменяются.

Не запускайте `import_existing.py` или `init_local.py` повторно для этого обновления. Новый суперпользователь тоже не нужен.

Архив рассчитан на схему из выданной M0/M1: `accounts.0001_initial` и `courses.0001_initial`. Если у вас есть самостоятельно добавленные миграции courses с номерами 0002/0003, сначала нужна сверка: не заменяйте их одноимёнными файлами обновления. Неизвестные изменения вашего локального кода не включены в этот архив.

## Что готово

### Создание курса

«Управление курсами» открывает карточки настоящих черновиков, опубликованных программ и архива. Основное действие — **Создать курс**.

Мастер идёт последовательно: направление → сложность → название → описание и результаты обучения → обложка → проверка. Можно вернуться назад. Поля сохраняются на сервере по мере заполнения. Обложка необязательна. Незаконченный мастер оставляет черновик, который можно открыть позже.

### Наполнение

Слева — разделы, уроки и шаги; справа — редактор выбранного элемента. Кнопка «Добавить урок» создаёт очередной «Урок N». Уроки и разделы можно переименовать, скопировать, удалить из черновика и переставить. Стрелки работают клавиатурой; перетаскивание меняет порядок среди соседей одного уровня. Перенос между разными разделами/уроками перетаскиванием не реализован.

У урока есть переключатель доступности студентам. Скрытые уроки остаются в черновике и в сохранённой версии, но не выдаются студентам. Шаги можно помечать обязательными или дополнительными. Детальный учёт изучения каждого теоретического шага относится к M4; сейчас сохраняется прежний расчёт прогресса по урокам, а обязательность учитывается при проверке тестов урока.

Поддержаны:

- **Статья:** визуальное редактирование, жирный/курсив, заголовки, списки, блоки кода, ссылки и изображения. Вставка из буфера выполняется как обычный текст. Сервер очищает HTML от неподдерживаемых тегов и атрибутов.
- **Видео:** загрузка MP4/WebM либо ссылка. Загруженное совместимое видео воспроизводится внутри урока; ссылка открывается отдельно, чужие сайты не встраиваются автоматически.
- **PDF:** просмотр внутри урока и открытие отдельно.
- **Презентация:** PPT/PPTX для скачивания; дополнительный PDF для встроенного просмотра.
- **Документ:** DOC/DOCX для скачивания; дополнительный PDF для встроенного просмотра.
- **Внешняя ссылка:** адрес HTTP/HTTPS.
- **Тест:** один правильный ответ, несколько правильных ответов или короткий ответ.
- **Задача C++:** конструктор условия и настроек, без запуска программ до M3.

Загрузки показывают реальный процент передачи файла, позволяют отмену и повтор при ошибке. Файл прикрепляется к черновику только после успешного ответа сервера. Максимум — 500 МБ на материал, 10 МБ и 30 миллионов пикселей на изображение. Поддержка MP4 зависит от кодека браузера: файл с расширением MP4 не обязательно содержит совместимое видео. Сервер поддерживает byte-range запросы для перемотки и просмотра частей PDF.

Убрали из шага файл — он перестал быть выбран в черновике. Сам физический файл не удаляется, чтобы не повредить опубликованные версии. Автоматическая очистка неиспользуемых загрузок пока не включена; за свободным местом нужно следить.

### Тесты

В редакторе добавьте вопрос, выберите тип, заполните варианты и отметьте правильные. Для короткого ответа задайте допустимые ответы по одному на строку; регистр можно учитывать или игнорировать. Пробелы по краям ответа не учитываются, внутренние сохраняются.

Для нескольких ответов засчитывается только точное совпадение набора, без лишних и пропущенных вариантов. Вес вопросов одинаковый. Порог и награда задаются отдельно для каждого теста: по умолчанию **100% и 5 баллов**. Повторное успешное прохождение баллов не добавляет. Объяснение вопроса показывается после отправки попытки.

### Конструктор C++

Сохраняются условие, формат ввода/вывода, примеры, стартовый код C++20, эталонное решение, скрытые тесты, лимиты времени/памяти и награда. Закрытые данные доступны только владельцу курса и администратору.

**Исполнение и автоматическая проверка программ не реализованы — это M3.** Курс с доступным студентам шагом C++ пока опубликовать нельзя, даже если шаг дополнительный. Для публикации теории и обычных тестов скройте отдельный урок с задачей C++ или удалите этот шаг из публикуемого черновика. Настройки скрытого урока останутся доступны преподавателю.

### Сохранение

Автосохранение запускается примерно через 0,9 секунды после изменения. Есть кнопка **Сохранить** и сочетание **Ctrl+S**. Статус показывает, сохранены ли правки и когда. При ошибке текст не исчезает: исправьте данные/соединение и повторите сохранение.

У каждой сохранённой редакции есть номер. Устаревшая вкладка не может молча перезаписать новый вариант. При конфликте можно скачать свои локальные правки в JSON и затем загрузить актуальную серверную версию. Автоматического слияния и импорта скачанного JSON нет; файл служит резервной копией для восстановления нужных изменений. Черновики с кодом и скрытыми тестами конфиденциальны — не публикуйте этот JSON.

### Предпросмотр и публикация

**Предпросмотр** открывает сохранённый черновик с материалами и формами заданий. Ответы, скрытые тесты и эталонное решение в него не передаются. Настоящие баллы, попытки и прогресс не меняются; кнопки проверки ответов в предпросмотре нет.

**Опубликовать** сначала проверяет курс. Если есть ошибки, появляются кнопки перехода к проблемным шагам. После подтверждения создаётся новая самостоятельная версия курса и показывается ссылка на неё.

Первая публикация появляется в каталоге. Следующие правки остаются в черновике. Повторная публикация создаёт новую версию для новых студентов; прежняя исчезает из общего каталога, но остаётся в библиотеке уже записанных. Их уроки, файлы, баллы и прогресс сохраняются. Кнопка «Продолжить» ведёт на их версию. Повторно записаться на другую версию той же программы через обычный интерфейс нельзя — это предотвращает повторное получение баллов за обновление курса.

Кнопка **⋯** в редакторе убирает курс в архив или возвращает его. Архив закрывает новые записи, сохраняя историю обучения. Массовый перенос студентов между версиями, удаление истории и автоматическое слияние результатов в M2 не входят.

Редактирование контента через старые POST-адреса закрыто ответом 410. В технической Django-панели контент доступен только для чтения; направления можно настраивать как прежде. Рабочее место преподавателя — `/management/`.

## Проверка после обновления — около 10 минут

1. Войдите прежним администратором. Убедитесь, что старые курсы появились в управлении и прежние баллы на месте.
2. Создайте новый курс мастером. Добавьте урок, статью и тест с одним вопросом; задайте правильный ответ.
3. Подождите статуса «Сохранено», обновите страницу. Текст и вопросы должны остаться.
4. Скопируйте урок; переставьте стрелками или перетаскиванием; удалите копию из черновика.
5. Прикрепите небольшое видео/PDF. Проверьте загрузку, отмену, повтор и предпросмотр.
6. Опубликуйте курс. Под студентом в приватном окне добавьте его в библиотеку, пройдите тест. Начисляются 5 баллов. Повторите — новых баллов нет.
7. Под преподавателем измените текст и название курса, сохраните. Студент должен видеть прежние материалы даже до следующей публикации.
8. Опубликуйте новую версию. Старый студент продолжает свою программу, новый студент получает новую.
9. Откройте один черновик в двух вкладках. Измените и сохраните в первой, затем во второй: во второй должен появиться конфликт, первая версия не перезаписывается.
10. Добавьте шаг C++ и попробуйте публикацию — сервер объяснит, что исполнение будет подключено в M3.

Дополнительно проверьте интерфейс в своём браузере на ширинах 360/768/1440 px и клавиатурой. Этот архив проверен автоматическими серверными тестами и проверкой синтаксиса JavaScript, но реальная визуальная проверка и воспроизведение ваших файлов в Windows-браузере здесь не выполнялись.

## Что проверено автоматически

35 тестов M1/M2: роли и владение, CSRF, вход без локальной 2FA, приглашения и сессии; создание и сохранение черновика; конфликт редакций; проверки публикации; идемпотентная публикация; сохранение старой версии и прогресса; архив; запрет повторной записи на другую версию; типы ответов, порог и награда; отсутствие повторных баллов; очистка HTML; закрытость чужих и скрытых файлов; приватность конструктора C++; предпросмотр без изменения результатов; загрузки, проверка изображений, range-ответы, выдача общего файла студенту новой версии; закрытие старых методов редактирования.

Отдельный тест поднимает структуру M1, создаёт курс с наградой 9 баллов и прогрессом студента, затем применяет миграции M2. Идентификаторы уроков, баллы и прогресс сохраняются. Повторный импорт старых курсов не создаёт копии черновиков.

PostgreSQL и нагрузочные/параллельные сценарии на настоящем сервере в этой среде не проверялись. Эта инструкция предназначена для локальной разработки, не для открытия runserver в интернете.

## Карта изменений

- `backend/studio/` — черновики, версии, файлы, проверки, API редактора, предпросмотр, тесты, импорт прежних курсов.
- `backend/courses/models.py` и новые миграции — видимость версии в каталоге, формат статьи, обязательность и настройки вопросов/наград.
- `backend/courses/views.py` и `services.py` — типы ответов, начисление баллов, запись на версию, закрытие старого редактора.
- `backend/access/media.py` — проверка доступа ко всем использующим файл версиям и выдача диапазонов.
- `backend/core/views.py` — каталог актуальных версий и продолжение своей программы.
- `frontend/templates/studio/`, `frontend/static/css/studio.css`, `frontend/static/js/studio.js` — полные файлы интерфейса.
- `frontend/templates/courses/lesson_detail.html`, `frontend/templates/core/home.html` — вывод новых материалов/тестов и переход к своей версии.

Очистка HTML реализована через Bleach: [документация](https://bleach.readthedocs.io/en/latest/clean.html). Файлы библиотек редактор не загружает с внешних CDN; оформление использует локальные шрифты M0.
