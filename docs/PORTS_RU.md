# Порты стандартного docker compose

| Компонент | Порт | Доступ |
|---|---|---|
| Сайт HTTP | 80/TCP | Снаружи; http://IP-СЕРВЕРА |
| Сайт HTTPS | 443/TCP | Снаружи; работает после задания IB_SITE и DNS |
| Django/Gunicorn | 8000/TCP | Только внутри Docker, не публикуется |
| PostgreSQL | 5432/TCP | Только внутри Docker, не публикуется |
| Docker daemon компилятора | 2376/TCP, TLS с клиентским сертификатом | Только judge ↔ runner в отдельной сети, не публикуется |
| Caddy admin | 2019/TCP | Loopback внутри proxy, не публикуется |
| Ollama, если включён compose.ai.yaml | 11434/TCP | Только внутри Docker, не публикуется |
| judge, autoquiz, Whisper, задачи C++ | Нет входящих портов | Используют внутренние соединения |
| Чат, видео, редактор, рейтинг, API | 80/443 | Через основной сайт |

Наружу открываются только 80/TCP и 443/TCP. **Порт 2375 не используется.** SSH для нового компилятора не нужен. Сокет Docker хоста не монтируется. UDP 443 не опубликован.

При первом запуске сборка скачивает образы и библиотеки: нужны исходящие HTTPS/HTTP и DNS. Сами студенческие программы исполняются без сети. AI выключен по умолчанию.

Для другого HTTP-порта добавьте в .env `HTTP_PORT=8080`; команда запуска прежняя, сайт http://IP-СЕРВЕРА:8080. Для привязки только к этому компьютеру — `BIND_IP=127.0.0.1`. Для HTTPS используйте стандартные внешние 80/443 либо настройте свой reverse proxy.

Фактические опубликованные порты: `docker compose ps`.

## Старая схема

compose.legacy.yaml и compose.sh используют прежние настройки: локально 127.0.0.1:8080, сервер 80/443, SSH VM обычно 22. Она сохранена для совместимости; основной путь теперь обычный compose.yaml.
