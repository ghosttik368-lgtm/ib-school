# Порты проекта

| Компонент | Внутренний порт | Публикация на хосте |
|---|---|---|
| Caddy HTTP | 80/TCP | Сервер: 80; локально: 127.0.0.1:8080 |
| Caddy HTTPS | 443/TCP | Сервер: 443; локально: 127.0.0.1:8443 |
| Django/Gunicorn | 8000/TCP | Нет, только web:8000 внутри Docker |
| PostgreSQL | 5432/TCP | Нет, только db:5432 внутри Docker |
| Ollama (AI-профиль) | 11434/TCP | Нет; по умолчанию контейнер выключен |
| Caddy admin API | 2019/TCP, loopback контейнера | Нет |
| SSH VM проверки C++ | Обычно 22/TCP на VM | Настраивается на VM; соединение только с сервера сайта |
| judge, judge-local, C++-задачи, runner-image | Нет входящего порта | Нет |
| autoquiz, Whisper | Нет входящего порта | Нет |
| Чат, рейтинг, видео, редактор, API | Через web | Те же 80/443, отдельные порты не нужны |

Локальный режим работает по HTTP: mapping 8443 зарезервирован, локальный HTTPS не настроен. В режиме --behind-proxy платформа принимает запросы на **127.0.0.1:8080** от существующего HTTPS-прокси этого же хоста; он должен передавать X-Real-IP.

Для обычного сервера открываются только **80/TCP и 443/TCP**. SSH администрирования сервера настраивается отдельно. 5432, 8000, 11434 и 2019 открывать в firewall не нужно.

Docker TCP API **2375/2376 не открываются**: локально используется Unix-сокет, серверный C++ использует SSH. UDP 443 в Compose не опубликован, HTTP/3 не требуется. Контейнеры с решениями C++ запускаются без сети.

При сборке/скачивании нужен исходящий HTTP/HTTPS к реестрам и пакетам и DNS. Для публичного сертификата нужен ACME. При AI=off учебный функционал не обращается к моделям.

Фактические порты: **sh compose.sh ps** или **py tools/dc.py ps**. Полная конфигурация sh compose.sh config содержит секреты: не пересылайте её целиком.

Отдельный запуск runserver использует 127.0.0.1:8000 и не относится к Docker-развёртыванию.
