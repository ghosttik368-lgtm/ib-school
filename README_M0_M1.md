# ИБ — M0 и M1

Полные файлы платформы, без ручной вставки фрагментов. Основа — ранее сохранённая версия cyber_school_full_platform.zip. Файлы на вашем Windows-компьютере не доступны: неизвестные изменения в них в этот архив не входят. Поэтому обновление запускаем в отдельной папке, а старую сохраняем.

## Что внутри

- M0: frontend/backend разделены; общий зелёно-белый стиль, крупный текст, единые поля, кнопки, таблицы, диалог, адаптивные стили и уменьшенные анимации; настройки SQLite/PostgreSQL.
- M1: регистрация по одноразовым приглашениям, вход/выход, роли студента/преподавателя/администратора, проверка владельца курса на сервере, обязательная 2FA для преподавателя и администратора, резервные коды, смена/восстановление пароля, блокировка, отзыв сессий, журнал действий, ограничения попыток и CSRF.
- Существующие курсы, уроки, тесты, рейтинг, профиль и чат сохранены из базовой версии. Компилятор C++ и расширенный конструктор будут отдельными модулями.

Frontend — HTML-шаблоны, CSS, JavaScript. Backend — Django/Python. Node.js и npm для запуска не нужны.

## 1. Распаковать и установить

Остановите старый сервер: Ctrl+C. Сделайте резервную копию старой папки целиком, включая базу, media, .env и миграции.

Распакуйте архив **в новую папку** `C:\Users\NIK\Desktop\ib_m0_m1`. Не заменяйте старую папку целиком. В новой папке должны лежать frontend, backend, tools, deploy, requirements.txt и этот README.

В VS Code: Файл → Открыть папку → новая ib_m0_m1. Терминал → Создать терминал (PowerShell). Все команды ниже выполняйте из корня новой папки.

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Активация окружения не требуется. Если версия не найдена, `py --list` покажет установленные версии; нужен Python 3.10 или новее.

## 2. Перенести вашу базу

Выполняйте **до** init_local.py и migrate. Вставьте путь к старой папке проекта без кавычек, когда терминал спросит. Скрипт понимает как старое расположение manage.py в корне, так и новую папку backend.

```powershell
$oldProject = Read-Host "Полный путь к СТАРОЙ папке проекта без кавычек"
.\.venv\Scripts\python.exe tools\import_existing.py --from "$oldProject"
```

Ожидается сообщение «Скопированы база, загрузки, история миграций и имеющийся .env». Источник остаётся без изменений. Аккаунты, пароли, курсы, прогресс и баллы переходят с базой. Старые сеансы потребуют нового входа.

При несовпадении моделей или отсутствии миграций импорт останавливается. Не удаляйте миграции и не применяйте --fake. Пришлите ошибку и текущие исходники без .env, базы и личных загрузок. Если импорт прервался, повторяйте в заново распакованную папку.

Если сознательно начинаете с пустой базы, пропустите только этот раздел. В архиве нет готовой базы и тестовых аккаунтов.

## 3. Подготовить и запустить

```powershell
.\.venv\Scripts\python.exe tools\init_local.py
.\.venv\Scripts\python.exe backend\manage.py check
.\.venv\Scripts\python.exe backend\manage.py makemigrations --check --dry-run
.\.venv\Scripts\python.exe backend\manage.py migrate --plan
.\.venv\Scripts\python.exe backend\manage.py migrate
.\.venv\Scripts\python.exe backend\manage.py test access
```

Ожидается `System check identified no issues`, `No changes detected`, миграции OK и тесты OK. При ошибке остановитесь и сохраните её текст.

Инициализатор создаёт уникальные ключи в корневом .env и добавляет недостающие настройки, не заменяя имеющиеся. Не отправляйте .env в чат. Для локального запуска нужны DJANGO_DEBUG=1 и DJANGO_ALLOWED_HOSTS=127.0.0.1,localhost. Если в импортированном .env были настройки интернет-сервера, локально исправьте эти два значения.

Если нет существующего суперпользователя, создайте его:

```powershell
.\.venv\Scripts\python.exe backend\manage.py createsuperuser
```

Логин/пароль задайте свои; ввод пароля в терминале не отображается. После импорта используйте прежнего владельца, нового создавать не обязательно.

Запуск:

```powershell
.\.venv\Scripts\python.exe backend\manage.py runserver 127.0.0.1:8000
```

Откройте **http://127.0.0.1:8000/**. Терминал оставьте открытым. Остановка — Ctrl+C. Следующий запуск требует только последней команды из той же папки.

## 4. Первый вход и пользователи

1. Введите логин и пароль владельца.
2. Откроется подключение 2FA. Отсканируйте QR в приложении-аутентификаторе с TOTP или введите ключ вручную; введите шестизначный код. QR формируется локально.
3. Скачайте восемь резервных кодов и храните отдельно от пароля. Они показываются один раз; каждый подходит для одного входа.
4. Откройте «Пользователи» слева или http://127.0.0.1:8000/access/people/.
5. Во вкладке «Приглашения» создайте код на 1, 7 или 30 дней. Передайте студенту. Одно приглашение — один аккаунт.
6. В приватном окне браузера откройте регистрацию. Введите логин, курс обучения, пароль дважды, приглашение. Новый аккаунт всегда студент.
7. Для преподавателя откройте его пользователя под админом, выберите роль и подтвердите своим паролем и свежим кодом 2FA. При новом входе преподаватель подключит 2FA и сможет редактировать собственные курсы.

Код 2FA, использованный для входа, нельзя повторно применить к изменению роли: дождитесь следующего кода (обычно 30 секунд). При потере телефона используйте резервный код.

Администратор платформы управляет всеми курсами и обычными аккаунтами. Суперпользователь — владелец с технической панелью /admin/. Статус is_staff сам по себе больше не даёт права управления курсами. Старые курсы без автора доступны для редактирования администратору.

## 5. Проверить руками

- После импорта проверьте прежние курсы, загрузки, баллы и библиотеку.
- Студент открывает /management/ и /access/people/ — получает отказ.
- Преподаватель открывает чужой курс в управлении — получает отказ.
- Повторное приглашение не принимается.
- Изменение пароля завершает старые сеансы; блокировка и назначение роли отзывают сеансы.
- Профиль → Безопасность: подключение второго фактора, перевыпуск резервных кодов, завершение всех сеансов.
- /access/components/ доступна администратору: проверьте диалог клавиатурой и Escape.
- В F12 → режим устройств проверьте 360, 768 и 1440 px. Отключите анимации в настройках Windows и проверьте уменьшение переходов.

Забытый пароль: администратор проверяет личность вне сайта и выдаёт одноразовый код на 30 минут. На странице восстановления пользователь задаёт новый пароль. Второй фактор этим не отключается.

Если потеряны телефон и резервные коды, администратор отдельно сбрасывает 2FA после проверки личности. Для владельца есть аварийная команда **только в терминале сервера**, пароль она не меняет:

```powershell
.\.venv\Scripts\python.exe backend\manage.py recover_owner ВАШ_ЛОГИН --confirm
```

После этого подключите 2FA снова. Не удаляйте MFA_ENCRYPTION_KEY из .env: он нужен для расшифровки второго фактора.

Очистка просроченных записей (можно ежедневно):

```powershell
.\.venv\Scripts\python.exe backend\manage.py clean_access_limits
.\.venv\Scripts\python.exe backend\manage.py clearsessions
```

## 6. Файлы и ограничения

frontend/templates — полные страницы; frontend/static — стили и скрипты; backend/access — M1; backend/accounts — пользователь; backend/courses — курсы; backend/config — настройки; tools — установка/перенос; deploy — PostgreSQL.

Это восстановленная сборка после потери временной рабочей папки. Повторно выполнены check, миграции SQLite и 12 сценариев автотестов. PostgreSQL и визуальная проверка браузером здесь не выполнены; эти пункты приёмки M0 остаются открытыми. Не выдаём локальную сборку за окончательно проверенный интернет-сервер.

Первый запуск оставлен на SQLite, чтобы не смешивать перенос с заменой базы. PostgreSQL описан в docs/POSTGRESQL.md. runserver и DEBUG=1 — только локально. Не открывайте порт 8000 роутера. HTTPS, reverse proxy, резервные копии, ограничения загрузок и эксплуатационная проверка относятся к M8; изоляция компилятора — к M3.

Ограничитель учитывает непосредственный IP и логин. За прокси требуется отдельно согласовать доверие к IP-заголовкам и лимиты, иначе пользователи разделят IP-лимит прокси. Защищённая выдача видео пока без оптимизации больших файлов и HTTP Range.
