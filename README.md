# ИБ — обучающая платформа

Курсы, уроки, материалы, тесты, C++ с автоматической проверкой, сообщения, рейтинг и аналитика преподавателя. Whisper распознаёт видео, Qwen готовит черновик теста для проверки преподавателем. Оформление: логотип академии, Magistral и Montserrat, тёмно-синий и золотой из брендбука.

## Запуск на Windows

Нужны работающий [Docker Desktop с WSL 2](https://docs.docker.com/desktop/setup/install/windows-install/) и [Python 3.10+](https://www.python.org/downloads/windows/). В Docker должны использоваться Linux-контейнеры. Устанавливать Django, Ollama или компилятор в Windows отдельно не нужно.

1. Скачайте **Code → Download ZIP** с GitHub и распакуйте в новую папку либо клонируйте репозиторий.
2. Откройте PowerShell в папке с `compose.yaml`.
3. Выполните:

```powershell
py tools/ib.py start
```

Или дважды нажмите `START.cmd`. При первом запуске команда создаст настройки и ключи, соберёт образы, применит миграции, скачает Qwen и Whisper и запустит все сервисы. Скачивание моделей занимает время; повторный запуск использует сохранённые файлы.

Откройте **http://localhost:8080**. При повторных запусках используется та же команда; виртуальное окружение активировать не нужно.

Для первой установки потребуется интернет и несколько гигабайт на модели и образы. Память и скорость обработки видео зависят от компьютера; 1000 заведённых аккаунтов не означают 1000 одновременных пользователей.

## Загрузить 1000 выданных аккаунтов

Архив **IB_ACCOUNTS_1000_PRIVATE.zip** передаётся отдельно. Его нет на GitHub. Распакуйте, например, в `D:\IB_ACCOUNTS_1000_PRIVATE`.

После первого запуска сайта, **до создания любых пользователей**, выполните:

```powershell
py tools/ib.py import-accounts "D:\IB_ACCOUNTS_1000_PRIVATE\accounts.json"
```

Готово: **student001–student850**, **teacher001–teacher100**, **admin001–admin050**. Индивидуальные пароли находятся в `credentials.csv` из приватного архива. Для первоначального входа используйте `admin001`; он также имеет доступ к технической панели `/admin/`. Остальные 49 администраторов управляют платформой через её интерфейс. При первом входе каждый пользователь меняет выданный пароль.

Передавайте человеку только его строку из таблицы. Полный архив и таблицу хранит ответственный администратор. Импорт откажется работать, если пользователи уже существуют; существующая база не очищается.

Docker использует PostgreSQL: **не копируйте SQLite-файл в Docker-том**. Команда выше импортирует те же 1000 аккаунтов из `accounts.json` в PostgreSQL. В архиве также есть готовая `accounts.sqlite3` для отдельного запуска через `runserver`; инструкция находится внутри архива.

## Обновить уже работающий проект

В существующей папке Git-проекта:

```powershell
py tools/backup_compose.py
git pull --ff-only
py tools/ib.py start --build
```

Первая команда сохраняет резервную копию Docker-базы, материалов и ключей. Не удаляйте `.env.deploy` и Docker-тома. Если Git сообщает о локальных изменениях, остановитесь и сохраните их; не выполняйте `reset --hard`.

Если работаете без Git, используйте новую папку из полного архива для новой установки. Чтобы обновить старую установку без потери локальных правок, используйте Git либо предварительно сравните файлы. Для запуска через `runserver` после обновления исходников нужна новая миграция: `py backend/manage.py migrate` в вашем окружении.

## Повседневные команды

```powershell
py tools/ib.py start
py tools/ib.py status
py tools/ib.py check
py tools/ib.py stop
```

`check` проверяет Django, реальный ответ Qwen, Whisper и реальную компиляцию C++ с проверкой ограничений. `stop` останавливает контейнеры и сохраняет данные. **Не используйте `docker compose down -v`: эта команда удаляет тома с данными.**

## Перенос на флешке без интернета

На исходном компьютере после успешного запуска всех сервисов:

```powershell
py tools/ib.py export-usb "D:\IB_USB"
```

Возьмите целиком папку `IB_USB` и отдельно приватный архив аккаунтов. В `IB_USB` находятся исходники, Docker-образы и обе модели. Одних YAML-файлов для автономного запуска недостаточно: [Docker сохраняет образы отдельным архивом](https://docs.docker.com/reference/cli/docker/image/save/).

На новой машине установите Docker и Python, скопируйте `IB_USB` на диск, откройте PowerShell в `IB_USB\project`:

```powershell
py tools/ib.py import-usb ".."
py tools/ib.py import-accounts "D:\IB_ACCOUNTS_1000_PRIVATE\accounts.json"
```

Затем открывайте **http://localhost:8080**. Для последующих запусков без сети: `py tools/ib.py start --offline`.

Подробности и ограничения переноса: [docs/USB_RU.md](docs/USB_RU.md). Комплект рассчитан на одинаковую архитектуру процессоров, например Intel/AMD x64 → x64. Установщики Docker, WSL и Python в него не входят: подготовьте новую машину заранее.

## Сервер кафедры

На Linux нужен Docker Engine с Compose и Python 3.10+. Используйте `python3` вместо `py`; остальные команды те же. Локальный режим слушает только `127.0.0.1`. Для просмотра с рабочего компьютера можно открыть SSH-туннель: `ssh -L 8080:127.0.0.1:8080 user@SERVER_IP`.

Для общего доступа по домену, HTTPS и выделенной VM проверки C++ передайте администратору [серверную инструкцию](docs/DEPLOY_ADVANCED_RU.md). Локальный проверяющий C++ использует Docker-сокет; этот режим не предназначен для публикации в интернет. Не меняйте его привязку на `0.0.0.0`.

Исторические инструкции M1–M6 перенесены в `docs/history`; для текущей установки начинайте с этого README.
